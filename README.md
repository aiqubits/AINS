## 项目简介

AINS 是一个面向企业级场景需求的 AI 原生系统框架，旨在为企业提供 AI 技术落地解决方案。

不再区分传统 Web 架构角色设计，AINS 是为个人打造的团队型系统，包含前端、后端、数据库、测试、运维、架构师、产品经理等角色。

高性能，高可靠，易扩展，AI Coding 友好。

## 核心特性

- **AI-Native 架构**：从底层设计即为 AI 场景优化
- **模块化设计**：核心组件可插拔，按需组合
- **全端支持**：基于 Webshelf 的全端实现
